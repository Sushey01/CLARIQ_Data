📍 WHERE ARE MY FILES?

PDFs (your input)                → data/pdfs/
Extracted chunks (JSON)          → data/raw/curriculum_chunks.json
Knowledge base (CSV)             → data/processed/rag_knowledge_base.csv
All datasets                     → data/processed/
Vector database (embeddings)     → db/chroma_db/
Python scripts                   → src/

─────────────────────────────────────────────────────────────────

🚀 HOW TO RUN THE PIPELINE

Step 1: Extract text from PDFs
  $ python src/pipeline/extract_curriculum.py
  
Step 2: Create embeddings
  $ python src/embeddings/build_vector_db.py
  
Step 3: Search (interactive)
  $ python src/embeddings/search_vector_db.py
  
Step 4: Run full RAG system
  $ python src/rag/working_rag_system.py

─────────────────────────────────────────────────────────────────

📚 SCRIPT PURPOSES

PIPELINE (data extraction & processing):
  • extract_curriculum.py       → PDFs → JSON chunks
  • json_to_csv.py             → JSON → CSV
  • create_rag_tutor_data.py   → Prepare tutor data

EMBEDDINGS (vector search):
  • build_vector_db.py         → Create vector database
  • search_vector_db.py        → Search similar chunks

ML (machine learning datasets):
  • create_labeled_datasets.py         → Labeled data
  • create_proper_ml_datasets.py       → ML formats
  • create_training_csv.py             → Training data

RAG (retrieval-augmented generation):
  • working_rag_system.py              → Full RAG chatbot
  • rag_tutor_implementation.py        → Tutor features
